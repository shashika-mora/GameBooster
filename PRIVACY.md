# Privacy

GameBooster stores game paths, profiles, appearance and sampling preferences, session records, and recovery state locally. Recovery records can include a game's process ID, start time, and original priority so that another process with a reused ID is never modified. Monitoring samples stay in memory. Local logs record operation outcomes.

No analytics, accounts, cloud sync, or app network calls are implemented. Gaming setup buttons open Windows Settings; any updates or other connectivity on those pages are managed by Windows. Removing a game from the library retains its profile and session history. Removing the application does not automatically remove its local data.
